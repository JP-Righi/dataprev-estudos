# Usar junto com o Estratégia

Este pacote está pronto para uso com os PDFs oficiais. **Não foi criado nem alterado um caderno na sua conta do Estratégia nesta etapa.**

Se preferir responder lá, use os metadados dos cartões para localizar cada questão: banca FGV, órgão, cargo, tipo da prova e número original. O número exibido pelo banco pode ser um identificador próprio; confirme o enunciado no PDF.

Sugestões de nomes para organizar os cadernos:

- DATAPREV — Português — microtemas (32 questões).
- DATAPREV — Inglês — ciclo 1 (10 questões).
- DATAPREV — Lógica — ciclo 1 (16 questões).

Adicione apenas a questão de cada cartão, na ordem do guia, quando a plataforma permitir. Se uma questão não estiver disponível, use seu link oficial: isso não impede a sessão. Não é preciso coletar todas as questões da banca antes de começar.

Estas são orientações de organização, não instruções verificadas da interface atual do Estratégia.
